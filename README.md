# Guess the Accent!

[Play the game](https://natpsr.github.io/BUULI-guess-the-accent/)

A BUULI listening adventure for Burapha University Open House.

Five original recordings: American, British, Indian, Korean, and Chinese English. Each speaker has one scored accent guess and two unscored listening-experience questions.

No login, database, analytics, or external gameplay services. Playback uses 0.8x speed with pitch preservation where supported.

## Audio replacement
Send a replacement MP3 and its accent name to the project chat; no coding is required. Files are mapped in assets/audio/README.md.

## Verification
All five recordings started successfully in the published browser game. Full playthrough, scoring, saved experience answers, and restart were checked. Physical iPhone/Android testing remains pending. Review cards currently offer listening prompts; recording-specific accent explanations still require a listening review.
