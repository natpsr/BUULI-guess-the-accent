TO REPLACE A RECORDING
The easiest option: send the new MP3 to this chat and say which accent it replaces.
No code editing is needed. The matching file can be replaced and the website
republished while preserving the website address and visitor QR code.
If replacing files yourself, use the matching filename above and keep MP3 format.

SCORING
Only the accent guess counts: 20 points per correct answer, maximum 100.
Understanding and listening-experience answers are kept only in memory and
shown in the results. Restarting or refreshing clears them.

PUBLICATION
